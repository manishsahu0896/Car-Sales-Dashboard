Car Sales Dashboard | Power BI
Project Overview

This project is an interactive Car Sales Dashboard built using Microsoft Power BI. It provides insights into car sales performance, brand-wise quantity, pricing, and visual analytics through an attractive and user-friendly dashboard.

 Features
 Brand-wise Sales Analysis
 Interactive Brand Selection
 Quantity Analysis
 Price Analysis by Brand
 Car Image Gallery
 Clean and Interactive Dashboard Design
 Easy Navigation Between Brand Pages
 Tools & Technologies
 
Microsoft Power BI
Power Query
DAX
Excel / CSV Dataset
